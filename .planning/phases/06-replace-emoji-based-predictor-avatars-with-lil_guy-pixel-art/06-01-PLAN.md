<objective>
Replace the emoji + bgColor predictor avatar system with deterministic `lil_guy` pixel art avatars, and refactor PredictorEditor to let users regenerate their predictor's lil_guy avatar.

**Purpose:** Replace static emoji/color avatars with unique, deterministic 16x16 pixel art characters keyed to each predictor's id — the retro pixel-art aesthetic the project is built around. Users can re-roll their avatar via a Regenerate button that stores an optional seed override.

**Output:** Refactored PredictorAvatar rendering LilGuy SVGs, PredictorEditor with Regenerate flow, updated Predictor type (backward-compatible), updated stories/tests, all consumers working unchanged.
</objective>
