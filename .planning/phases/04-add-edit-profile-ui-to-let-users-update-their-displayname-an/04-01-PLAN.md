<objective>
Add an Edit Profile UI so logged-in users can update their displayName and avatar URL directly from the profile page.

Output:
- `updateUserProfile()` helper in auth-helpers.ts
- `updateProfile` action in auth-store.ts
- `EditProfileForm` molecule component with pixel-art styling
- Integration into ProfileTemplate + i18n strings
</objective>

    **`EditProfileForm.tsx`:**
    ```tsx
    import React, { useState } from 'react';
    import { useAuthStore } from '@store/auth-store';
    import { Button } from '@atoms/Button/Button';
    import { Typography } from '@atoms/Typography/Typography';
    import './EditProfileForm.css';

    export interface EditProfileFormProps {
      onClose: () => void;
      translations: {
        editProfile: string;
        displayName: string;
        avatarUrl: string;
        save: string;
        cancel: string;
        profileUpdated: string;
        updateError: string;
      };
    }

    export const EditProfileForm: React.FC<EditProfileFormProps> = ({ onClose, translations }) => {
      const user = useAuthStore((s) => s.user);
      const updateProfile = useAuthStore((s) => s.updateProfile);
      const [displayName, setDisplayName] = useState(user?.displayName || '');
      const [avatarUrl, setAvatarUrl] = useState(user?.avatarUrl || '');
      const [saving, setSaving] = useState(false);
      const [success, setSuccess] = useState(false);
      const [error, setError] = useState('');

      const handleSubmit = async (e: React.FormEvent) => {
        e.preventDefault();
        if (!displayName.trim()) return;
        setSaving(true);
        setError('');
        setSuccess(false);
        try {
          await updateProfile(displayName.trim(), avatarUrl.trim() || undefined);
          setSuccess(true);
          setTimeout(onClose, 1500);
        } catch (err) {
          setError(err instanceof Error ? err.message : translations.updateError);
        } finally {
          setSaving(false);
        }
      };

      return (
        <form className="edit-profile-form" onSubmit={handleSubmit}>
          <Typography variant="h3" className="edit-profile-form__title">
            {translations.editProfile}
          </Typography>

          {success && (
            <div className="edit-profile-form__success">
              <Typography variant="body">{translations.profileUpdated}</Typography>
            </div>
          )}

          {error && (
            <div className="edit-profile-form__error">
              <Typography variant="body">{error}</Typography>
            </div>
          )}

          <div className="edit-profile-form__field">
            <label className="edit-profile-form__label" htmlFor="edit-display-name">
              {translations.displayName}
            </label>
            <input
              id="edit-display-name"
              className="edit-profile-form__input"
              type="text"
              value={displayName}
              onChange={(e) => setDisplayName(e.target.value)}
              required
              minLength={1}
              maxLength={50}
              disabled={saving}
            />
          </div>

          <div className="edit-profile-form__field">
            <label className="edit-profile-form__label" htmlFor="edit-avatar-url">
              {translations.avatarUrl}
            </label>
            <input
              id="edit-avatar-url"
              className="edit-profile-form__input"
              type="url"
              value={avatarUrl}
              onChange={(e) => setAvatarUrl(e.target.value)}
              placeholder="https://example.com/avatar.png"
              disabled={saving}
            />
          </div>

          <div className="edit-profile-form__actions">
            <Button type="submit" variant="primary" size="md" disabled={saving || !displayName.trim()}>
              {translations.save}
            </Button>
            <Button type="button" variant="secondary" size="md" onClick={onClose} disabled={saving}>
              {translations.cancel}
            </Button>
          </div>
        </form>
      );
    };
    ```

    Key design decisions:
    - **Inline form** (not modal) — simpler UX, less CSS. The form appears below the profile header when the user clicks "Edit Profile". This matches the pixel-art aesthetic of the app.
    - **displayName is required** with minLength 1 and maxLength 50. Trimmed before save.
    - **avatarUrl is optional** with `type="url"` — browser validates URL format. If empty, stored as `undefined` (clears photoURL).
    - **Success state** shows a brief message then auto-closes after 1.5s.
    - **Error state** shows the error message inline.
    - **Button component** from `@atoms/Button/Button` — already used in ProfileTemplate. **Do NOT create a raw `<button>` element.** Use the existing Button atom with `variant="primary"` for save and `variant="secondary"` for cancel. Verify the Button component accepts `type` prop and `disabled` prop by reading the Button atom first.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | `updateUserProfile()` | mitigate | Input is trimmed and length-limited (max 50 chars for displayName). avatarUrl goes through browser URL validation via `<input type="url">`. No HTML/markdown accepted — plain text fields. |
| T-04-02 | Spoofing | Firestore `users/{uid}` doc | mitigate | Firestore security rules should enforce `request.auth.uid == uid` — user can only write to their own doc. Verify rules exist for this. |
| T-04-03 | Information Disclosure | avatarUrl field | accept | Avatar URL is a user-provided external URL. The `<img>` tag loads it. No SSRF risk since it only loads images in the browser. CSP meta tag in BaseLayout already restricts image sources. |
| T-04-04 | Elevation of Privilege | `updateProfile()` Auth action | mitigate | Auth's `updateProfile()` only modifies the current user's own profile. No privilege elevation possible — identical to how `registerWithEmail` already calls it. |
| T-04-SC | Tampering | npm dependencies | mitigate | No new packages introduced — uses existing `firebase/auth` and `firebase/firestore` imports. |
