  <action>
    Fix two issues:

    1. **Scroll-through (mobile menu open):** When `menuOpen` is true, add `overflow: hidden` to `document.body` via a `useEffect` that runs when `menuOpen` changes. Clean up by resetting body overflow when menu closes or component unmounts. Use `document.body.style.overflow = 'hidden'` / `'unset'`.

    2. **Sticky not working:** The `.nav-bar` already has `position: sticky; top: 0; z-index: 100`. The most likely cause is a parent element with `overflow: hidden | auto | scroll` clipping the sticky context. Check the Astro `BaseLayout` wraps NavBar — if the parent has `overflow: hidden`, replace it with `overflow: clip` on the layout wrapper. Also add `overflow: clip` directly to `.nav-bar` and ensure the `z-index` is sufficient (100 is fine if no conflicting stacking context). Add `align-self: flex-start` if the parent is a flex container.

    Do NOT change the component's public API (props interface). Only fix behavior.
  </action>
  <verify>

  </verify>
