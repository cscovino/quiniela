  <action>
    Edit tsconfig.json with two changes:

    1. **TS6 baseUrl deprecation (TS5101):** Add `"ignoreDeprecations": "6.0"` to `compilerOptions`. This silences the TS5101 error for `baseUrl` which TypeScript 7.0 will drop, but Astro + Vite still depend on `baseUrl` for path alias resolution in TS6.
       - Add it as the first line after `"jsxImportSource": "react",` line
       - Do NOT remove `baseUrl` — Vite/astro path aliases read it

    2. **Expand `exclude` to cover build artifacts:** `astro check` (Astro language server) processes all files matching the `include` globs and crashes with OOM on bundled JS in `storybook-static/` and `coverage/`. Add:
       ```
       "exclude": ["dist", "storybook-static", "coverage", "functions/lib", "node_modules"]
       ```
       - `functions/lib/` contains compiled Cloud Functions JS (CommonJS modules that generate TS80001 warnings)
       - `node_modules` is explicit safety (TypeScript implicitly skips it, but Astro LSP may not)
       - Keep the existing `"dist"` entry

    The `include` field stays as `[".astro/types.d.ts", "**/*"]` — we want all source, just not build output.
  </action>
