  <action>
    Apply two independent sed transformations across all affected files.
    Order does not matter between these two sed passes (they target different parts of import lines).

    **Step A: Fix barrel import paths**
    Run three sed commands, one per component tier. Each replaces the duplicate path segment pattern:

    ```bash
    # Fix atoms: @atoms/Foo/Foo -> @atoms/Foo
    rg --pcre2 -l "from '@atoms/([^/'\"']+)/\1'" src/ --type-add 'src:*.{ts,tsx}' -t src | while read f; do
      sed -i '' "s|from '@atoms/\([^/']*\)/\1'|from '@atoms/\1'|g" "$f"
    done

    # Fix molecules: @molecules/Foo/Foo -> @molecules/Foo
    rg --pcre2 -l "from '@molecules/([^/'\"']+)/\1'" src/ --type-add 'src:*.{ts,tsx}' -t src | while read f; do
      sed -i '' "s|from '@molecules/\([^/']*\)/\1'|from '@molecules/\1'|g" "$f"
    done

    # Fix organisms: @organisms/Foo/Foo -> @organisms/Foo
    rg --pcre2 -l "from '@organisms/([^/'\"']+)/\1'" src/ --type-add 'src:*.{ts,tsx}' -t src | while read f; do
      sed -i '' "s|from '@organisms/\([^/']*\)/\1'|from '@organisms/\1'|g" "$f"
    done
    ```

    **Step B: Remove `import React from 'react'`**
    Run sed for standalone imports:

    ```bash
    # Remove standalone 'import React from 'react''
    rg -l "^import React from 'react';$" src/ --type-add 'src:*.{ts,tsx}' -t src | while read f; do
      sed -i '' "/^import React from 'react';$/d" "$f"
    done
    ```

    **IMPORTANT:** After Step B, some files will have an empty first line (blank line at top of file). Remove empty leading lines:

    ```bash
    # Remove leading blank lines from any affected files
    rg -l "^import React from 'react';$" src/ --type-add 'src:*.{ts,tsx}' -t src | while read f; do
      # Remove leading blank lines (sed approach)
      sed -i '' '/./,$!d' "$f"
    done
    ```

    After both sed passes, verify sample files for correctness:
    - Check `src/components/molecules/MatchCard/MatchCard.tsx` — barrel paths fixed, no import React
    - Check `src/components/organisms/NavBar/NavBar.tsx` — same
    - Check `src/services/live-data-service.ts` — barrel paths fixed

    - Run `pnpm build` to confirm imports resolve (may fail until edge cases are handled in Task 2)

  <action>
    After Task 1 removed `import React from 'react'`, build will fail on files that use `React.FC`, `React.ReactNode`, `React.useId()`, etc. Fix each file by (a) adding a direct import for the specific React members and (b) replacing `React.XXX` with `XXX`.

    **Approach:** Use a script that processes every file that had `import React from 'react'` removed:

    1. Find all files that still have `React.` references (the `React` symbol is now undefined):
    ```bash
    rg -n "React\." src/ --type-add 'src:*.{ts,tsx}' -t src | grep -v '\.stories\.' | grep -v 'node_modules'
    ```

    2. For each file, collect all unique `React.XXX` identifiers used, then:
       - Remove the namespace prefix (`React.FC` → `FC`, `React.ReactNode` → `ReactNode`, etc.)
       - Add `import { FC, ReactNode, useId, InputHTMLAttributes, CSSProperties, ElementType, FormEvent, AnchorHTMLAttributes, ButtonHTMLAttributes } from 'react';` with ONLY the identifiers used in that file

    3. For each file, the approach is deterministic based on what `React.` references exist:

    | React.X Identifier | Import Replacement | Code Replacement |
    |---|---|---|
    | `React.FC` | `import { FC } from 'react'` | `React.FC` → `FC` |
    | `React.ReactNode` | `import { ReactNode } from 'react'` | `React.ReactNode` → `ReactNode` |
    | `React.useId` | `import { useId } from 'react'` | `React.useId()` → `useId()` |
    | `React.InputHTMLAttributes` | `import { InputHTMLAttributes } from 'react'` | strip prefix |
    | `React.CSSProperties` | `import type { CSSProperties } from 'react'` | strip prefix |
    | `React.ElementType` | `import { ElementType } from 'react'` | strip prefix |
    | `React.FormEvent` | `import { FormEvent } from 'react'` | strip prefix |
    | `React.AnchorHTMLAttributes` | `import { AnchorHTMLAttributes } from 'react'` | strip prefix |
    | `React.ButtonHTMLAttributes` | `import { ButtonHTMLAttributes } from 'react'` | strip prefix |

    **Special cases (read files to decide):**
    - `Input.tsx` uses `React.InputHTMLAttributes` (extends it) and `React.useId()` — NEEDS `InputHTMLAttributes` + `useId` imports, AND `React.InputHTMLAttributes` → `InputHTMLAttributes`, `React.useId()` → `useId()`
    - `Checkbox.tsx` — same as Input
    - `Badge.tsx` uses `React.ReactNode` — NEEDS `ReactNode` import, REPLACE `React.ReactNode` → `ReactNode`
    - `Button.tsx` uses `React.AnchorHTMLAttributes` and `React.ButtonHTMLAttributes` — direct import + replace
    - `Typography.tsx` uses `React.ElementType` — direct import + replace
    - `Templates` with React.FC: same pattern

    **Sed approach for the common case (React.FC):**
    ```bash
    # Replace React.FC with FC across all affected files
    rg -l "React\.FC" src/ --type-add 'src:*.{ts,tsx}' -t src | grep -v '\.stories\.' | while read f; do
      sed -i '' 's/React\.FC/FC/g' "$f"
    done
    ```

    For less common cases, use targeted sed replacements:
    ```bash
    rg -l "React\.ReactNode" src/ --type-add 'src:*.{ts,tsx}' -t src | grep -v '\.stories\.' | while read f; do
      sed -i '' 's/React\.ReactNode/ReactNode/g' "$f"
    done
    ```

    Then add the direct import line to each file. The best approach is a script that:
    1. Scans each file for remaining `React.` patterns
    2. Builds the set of required imports
    3. Inserts the import line after any existing `import { ... } from 'react'` or at the top of the file

    After all replacements, run `pnpm build` to identify any remaining issues, fix them iteratively.
