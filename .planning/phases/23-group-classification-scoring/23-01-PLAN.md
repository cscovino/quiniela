<objective>
Score group classification bets when all group matches finish — implements SCORE-01

**Purpose:** When `updateGroupStandings` writes final standings to `group_standings/{groupId}`,
a new standalone `calculateGroupResults` Cloud Function (D-02) fires via `onUpdate` trigger (D-03)
to score all group classification bets against the actual standings. Uses D-06 algorithm
comparing `positions[]` against `standings[].teamId` by position index with
`SCORING.GROUP.EXACT_POSITION` (3 pts) for exact matches and `SCORING.GROUP.QUALIFIED` (1 pt)
for teams that qualified at the wrong position (D-07). Persists scored points to the
`group_bets` subcollection (D-09) and directly updates each predictor's stats document (D-10)
since `updatePredictorStats` only watches the `bets` subcollection. Guards against re-scoring
via `pointsCalculated` flag on trigger doc and `scoredAt` on bet docs (D-11).

**Output:**
- `functions/src/calculateGroupResults.ts` — pure `scoreGroupBet()` function + `calculateGroupResults` trigger handler
- `functions/src/__tests__/calculateGroupResults.test.ts` — unit tests for scoring logic
- `functions/src/index.ts` — added re-export of `calculateGroupResults`
</objective>

  3. **Pure function `scoreGroupBet`** (exported, directly testable):
     - Signature: `(positions: string[], standings: TeamStanding[]) => { points: number; exactMatches: number; wrongPositionMatches: number }`
     - Loop over `positions` array by index
     - For each position index i:
       - Compare `positions[i]` against `standings[i].teamId` — exact match → add `SCORING.GROUP.EXACT_POSITION` (3), increment `exactMatches`
       - Else if `standings.some(s => s.teamId === positions[i])` → add `SCORING.GROUP.QUALIFIED` (1), increment `wrongPositionMatches`
       - Else → 0 pts
     - Return `{ points, exactMatches, wrongPositionMatches }`
     - Handle edge cases: empty positions (0 pts, 0 matches), empty standings (0 pts, 0 matches)

  4. **Trigger handler `calculateGroupResults`:**
     - Per D-03: trigger path `tournaments/{tournamentId}/group_standings/{groupId}` via `functions.firestore.document(...).onUpdate(async (change, context) => {...})`
     - **Guard 1:** Check `after.pointsCalculated === true` → log and return null (prevents re-scoring on repeated standings updates)
     - **Guard 2:** Check `standings` exists and has length > 0 → log error and return null if missing
     - Extract `tournamentId` and `groupId` from `context.params`
     - Query `db.collection(tournaments/${tournamentId}/group_bets).where('groupId', '==', groupId).get()`
     - If empty: log, mark trigger doc `pointsCalculated: true`, return null
     - **Build batch:** `db.batch()`
     - For each bet doc: call `scoreGroupBet(bet.positions, standings)` with the returned `{ points, exactMatches, wrongPositionMatches }`
       - `batch.update(betDoc.ref, { points, scoredAt: FieldValue.serverTimestamp(), updatedAt: FieldValue.serverTimestamp() })`
       - Collect predictor scores in a `Map<string, { userId: string; points: number }>` keyed by `predictorId` for later stats update
       - Log each bet's scored points
     - `batch.update(change.after.ref, { pointsCalculated: true })`
     - `await batch.commit()`
     - **Direct predictor stats update:** after batch commit, loop through predictorScores map
       - Build stats ref path: `db.collection(users/${score.userId}/predictors/${predictorId}/stats).doc(tournamentId)`
       - `await statsRef.set({ totalPoints: FieldValue.increment(score.points), lastUpdated: FieldValue.serverTimestamp() }, { merge: true })`
       - Log each stats update
     - Return null

  **Import path:** `./scoring` (same directory, not `../src/config/scoring`).

  **Re-scoring guard:** Use `pointsCalculated: boolean` on the `group_standings` trigger document (matching `calculateMatchResult` pattern), plus `scoredAt: Timestamp` on each `group_bets` doc (prevents 0-point ambiguity per D-08 concern).

  **Logging:** Use `functions.logger.log()` and `functions.logger.error()` throughout, consistent with `calculateMatchResult.ts`.
